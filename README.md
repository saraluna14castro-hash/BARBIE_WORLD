
# 🎀 Barbie World ♡

¡Bienvenida a Barbie World! Un espacio digital inspirado en el universo Barbie, diseñado para explorar series, guardar recuerdos especiales y expresar emociones a través de una experiencia visual rosa, creativa y encantadora.

## 🌷 Descripción del proyecto

Barbie World es un sitio web desarrollado con HTML, CSS y JavaScript. Su propósito es ofrecer un espacio interactivo donde los usuarios puedan descubrir contenido, escribir sus pensamientos y conservar momentos importantes.

El proyecto integra una API externa para consultar series y utiliza LocalStorage para guardar información directamente en el navegador.

## ✨ Funcionalidades principales

### 🏠 Inicio
- Página principal de bienvenida.
- Navegación entre las diferentes secciones.
- Presentación del universo Barbie.

### 🎬 Catálogo
- Consulta de series mediante la API de TVmaze.
- Buscador de series.
- Visualización de imágenes, títulos y descripciones.

### 📔 Barbie Diary
- Formulario para escribir recuerdos.
- Selección del estado de ánimo.
- Almacenamiento de entradas en el navegador.

### 💌 Mis mensajitos
- Visualización de recuerdos guardados.
- Edición de títulos y contenidos.
- Eliminación de recuerdos.

### 🌷 Calendario de emociones
- Calendario interactivo.
- Selección de fechas.
- Registro de emociones y notas personales.
- Almacenamiento de información en LocalStorage.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura del sitio web.
- **CSS3:** diseño, estilos y presentación visual.
- **JavaScript:** interactividad y funcionalidades.
- **API TVmaze:** consulta de información de series.
- **LocalStorage:** almacenamiento de recuerdos y emociones.
- **Git y GitHub:** control de versiones y publicación del código.

## 🚀 Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalar la extensión Live Server.
4. Abrir el archivo `index.html`.
5. Seleccionar **Open with Live Server**.
6. Explorar las diferentes secciones de Barbie World.

## 🌐 API utilizada

**TVmaze API**

Se utiliza para consultar información de series mediante solicitudes HTTP.

Documentación: https://www.tvmaze.com/api
